## Durable R0.7B lessons

### Shared Commercial Authority

Generation, Script/Shooting semantic review, and Product Review converged on one provider-neutral authority model.

Retained invariants:

- positioning intent is not factual evidence;
- concrete product claims require authoritative facts;
- structural/mechanical facts do not imply ease, convenience, performance, fit, adequacy, reliability, or outcomes;
- mechanism/action/state facts should produce neutral observable descriptions unless additional support exists;
- a planned successful demonstration can itself imply a concrete claim;
- unsupported claims remain unresolved or use non-claim framing;
- reviewer diagnostics never become authority;
- reviewer authority is veto-only; Domain owners commit.

### Debugging / probe-cost discipline

Use:

```text
symptom
→ mechanism
→ subsystem
→ shared invariant
→ affected surfaces
→ systematic fix
→ deterministic regression
→ free CI
→ paid Product Probe only when it can produce new discriminating evidence
```

Do not return to isolated vocabulary patches or paid provider runs as debugging substitutes.
