# Upstream Governance

## Active files

- `UPSTREAM_COMPONENTS_V2.md` — current component/reference ledger.
- `UPSTREAM_POLICY_V2.md` — current reuse/dependency policy.

`UPSTREAM_COMPONENTS.md` and `UPSTREAM_POLICY.md` are historical bootstrap snapshots.

Other named FireRed/TransNet files preserve phase-specific audit/provenance evidence and are retained for traceability.

## Rule

An upstream can provide algorithms, implementation ideas or an approved dependency, but it never owns this repository's product semantics.

Direct adoption requires the applicable source/model/data/transitive/provider/license gate. Incompatible or unclear code may remain a research/algorithm reference without being copied or depended upon.

Strategic reference roles currently include FireRed-OpenStoryline, MoneyPrinterTurbo, CutClaw, BeatSync Engine and TransNetV2 as described by the Product Constitution/current ledger.
