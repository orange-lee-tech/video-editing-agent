## Stage 0.5 — Driver Store / platform gate

Additional local evidence:

- machine manufacturer/model: `LENOVO 20JTS1R400` (ThinkPad T470s, type 20JT);
- BIOS: `N1WET48W (1.27)`, dated 2018-05-28;
- the physical display device is started and still bound to `display.inf` / Microsoft Basic Display Adapter;
- `pnputil /enum-devices ... /drivers` reports no Intel matching driver package for the device;
- `pnputil /enum-drivers /class Display` reports only the Oray virtual-display package `oem29.inf`;
- therefore there is no signed Intel graphics package in the local Driver Store that can simply be rebound/restored.

Current official-source interpretation:

- Lenovo still publishes a T470s 20JS/20JT-specific Intel graphics driver path, but that OEM package is a Windows 10-era package;
- Intel still publishes `31.0.101.2115` for Intel HD Graphics 520 / 6th-generation graphics and exposes a Windows 11-family download, but the same Intel page marks 6th-generation graphics EOL and its detailed platform-support matrix is legacy-limited;
- therefore this Windows 11 build + 6th-generation host is **not** promoted to the ordinary supported Class-B hardware definition even if a vendor driver can be restored.

Driver restoration policy for this benchmark:

1. preserve the present Microsoft-Basic-Display state as Class-A degraded evidence;
2. attempt the Lenovo OEM graphics package first because it is platform-specific to T470s 20JS/20JT;
3. if the OEM installer rejects/fails on the current Windows 11 host, record that result rather than forcing a manual INF install;
4. only then consider Intel's generic `31.0.101.2115` package as a benchmark restoration experiment, using Intel's normal installer and no forced Have-Disk/DCH bypass;
5. keep Oray installed during restoration; only disable the virtual display temporarily later if adapter-selection evidence proves it interferes with a controlled benchmark;
6. do not update BIOS merely to satisfy the Preview benchmark.

A successful vendor-driver restoration on this machine provides **Class-A restored-vendor-driver evidence**, not universal Class-B performance proof.
