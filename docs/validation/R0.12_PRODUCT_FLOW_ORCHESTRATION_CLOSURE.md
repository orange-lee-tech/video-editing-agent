## 7. Evidence-driven repairs during closure

The live probe was deliberately allowed to expose failures rather than being weakened until green.

### ProductFlow typed-outcome harness

An early run showed that the CLI process can exit normally while returning a typed ProductFlow `outcome=failed` result. The Engineering workflow was repaired to parse the returned JSON and fail immediately unless `outcome == completed`.

This prevents shell/process success from being misreported as application success.

### Planning semantic vetoes

Early Planning attempts were rejected by the existing commercial/production Review owners because the controlled fixture implied an unsupported product capability or declared production resources inconsistent with the proposed capture plan.

The Review rules were **not** relaxed. The fixture was corrected to describe separate pre-existing reference visuals and to declare the actual operator/camera/tripod/resources available to the exercise.

### DeepSeek Director scalar schema

An early live Editing attempt produced a non-string `slot_id`. The strict parser correctly failed closed.

The production Director system prompt was strengthened to state the already-existing scalar type/range contract explicitly. The parser was not loosened and no numeric/string coercion was added.

A deterministic regression test now locks the prompt's scalar schema instructions.
