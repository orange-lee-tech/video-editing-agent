## Decision

The Stage-A ordinary product does **not** expose remote reference-URL input in 1.0.

Reason: current approved visual providers (Gemini/OpenAI adapters in this repository) are image-frame understanding providers. They do not provide a stable provider-neutral remote-video/native-video observation contract. Continuing to force remote references through full download → ffprobe → shot detection → frame understanding would overbuild the 1.0 reference path and conflate two different jobs:

- reference media: learn content/style/structure for Planning;
- user footage: exact source-time evidence for Editing/EDL.

Provider-neutral `ReferenceObservationPort`, remote-video-native observation, provider upload-media observation, and controlled image-only observation fallback are deferred to 2.0.

The ordinary Tkinter Planning surface therefore hides the unfinished reference-URL field and retains local reference-video input.
