## Durable product meaning

Reference URL is now an input convenience boundary, not a new media-authority class.

Remote reference acquisition may influence Planning only through reference-analysis evidence. It does not make remote reference video editable output footage, and it cannot supply visual Resolver candidates.

The ordinary-user fallback for unsupported/authenticated/protected/provider-disallowed references remains: obtain/save the reference through an allowed user/platform route, then select the resulting local reference file.
