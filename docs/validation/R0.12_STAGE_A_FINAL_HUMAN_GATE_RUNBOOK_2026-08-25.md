## 2. Human-Gate policy

This gate proves ordinary-user product usability, not developer tooling.

The Product Owner must be able to operate the product through the packaged GUI without requiring:

- repository checkout;
- Python;
- uv;
- Git;
- PowerShell / Command Prompt / Terminal knowledge.

Engineering shell commands may be used separately after the product run only to capture evidence such as source/output hashes. They are not part of the ordinary-user product path and may not be used to rescue a failing GUI workflow.

## 4. Gate A — packaged ordinary-user shell

PASS requires:

1. extract the accepted artifact to an ordinary user-controlled folder outside the repository;
2. launch `VideoEditingAgent.exe` by normal Explorer double-click;

5. create/select a Project Workspace outside the install tree;

## 5. Gate B — Planning-only

Use ordinary GUI inputs only.

PASS requires:

- configure the required reasoning/visual provider settings in the GUI;
- enter a normal short-video objective, audience, platform, message and filming constraints;
- optionally provide a supported local reference video;

Planning-only must remain a legitimate terminal state of the flexible production line.

## 6. Gate C — Editing-only with real speech

Planning enrichment must be disabled for this run.

Use one short external private sample with clear single-speaker original voice.

PASS requires:

- select local source footage through the GUI;
- choose/confirm an output destination in the external Workspace or another explicit user path;
- start Editing from the ordinary GUI;
- automatic workflow reaches a real final MP4;
- original/source voice is preserved and intelligible;
- trusted subtitles correspond to actual speech;
- subtitle timing is acceptable to a normal viewer;
- no fabricated words/subtitles are introduced;
- BGM, if present, does not bury speech;
- original source files remain unchanged;
- progress/failure/output location is understandable.

The already accepted no-speech Human baseline does not need to be repeated unless this packaged run exposes a regression.

### Cross-language compatibility check

This second run is a targeted compatibility check, not a new product-scope gate. Record whether speech preservation and subtitle grounding remain acceptable.
