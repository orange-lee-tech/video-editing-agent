## R0.3-C — current boundary

The next boundary is provider-neutral by design:

`ExtractedFrameSample -> ArtifactStore -> VisualFrameReference -> VisualUnderstandingPort -> VisualSemanticsProposal -> deterministic normalization`

A provider proposal is not Domain state and cannot create or modify a `ShotAnalysis` revision. The
future `UnderstandingService` owner remains responsible for validating and committing derived analysis.
