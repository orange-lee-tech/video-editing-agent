## Scope

R0.7A-2 migrated the active R0.1–R0.6 runtime time authority from integer milliseconds toward Architecture v0.2 exact rational `MediaTime`, while deliberately leaving SQLite schema/codec migration for R0.7A-3.

The work was split into two risk-controlled source batches.

## Architecture result

The active runtime can now distinguish:

```text
canonical exact media time
!=
human/legacy millisecond compatibility
!=
FFmpeg decimal execution formatting
```

This is required for VFR-safe derivative mapping and deterministic EDL rounding later.

## Deliberate temporary boundary

SQLite schema/codec remains the historical v1 persistence format until R0.7A-3.

Therefore a runtime Asset/Shot value that cannot be represented by the old codec must not be silently rounded for persistence. R0.7A-3 must add explicit codec v1 readers + codec v2 writers and transactional schema migration.

## Next phase

`R0.7A-3 — SQLite schema v2 + codec backward compatibility`

This is the highest-risk migration batch and must prove:

- existing v1 project database opens and migrates transactionally;
- old payload JSON remains readable without being rewritten as historical fiction;
- new exact rational media time persists losslessly;
- legacy remote/generated visual states migrate fail-closed;
- reopen/restart preserves exact records;
- migration is idempotent.
