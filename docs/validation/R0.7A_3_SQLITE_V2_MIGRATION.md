## Scope

R0.7A-3 migrated local structured persistence from the historical SQLite/codec v1 baseline to an explicit forward-compatible v2 boundary without rewriting historical record payloads.

Implemented:

- SQLite `user_version = 2`;
- supported schema initialization/migration from versions `0` and `1`;
- transactional schema migration with rollback on injected failure;
- idempotent `project_migrations` audit record;
- codec v1 reader + codec v2 writer;
- Asset codec v2 exact rational `duration`;
- Asset codec v2 explicit `usage_role`;
- Shot codec v2 exact rational `source_range`;
- conservative codec-v1 Asset role interpretation;
- legacy remote/generated/unknown visual states fail closed as `restricted_legacy_visual`;
- legacy local visual records retain the historical editable role because R0.1–R0.6 had no reference-video ingestion role;
- local media ingest can now carry an explicit usage-role declaration.

Historical v1 `payload_json` rows are deliberately left byte-for-byte unchanged by the schema migration. Compatibility is provided by version-dispatched decoding rather than rewriting history.

## Architecture result

The project now has three explicit persistence layers:

```text
historical payload shape
→ codec-version reader
→ current exact runtime model
```

and:

```text
current runtime model
→ codec v2 writer
→ immutable new record payload
```

Schema migration changes database capability/version metadata, not the meaning or bytes of already-committed historical JSON records.
