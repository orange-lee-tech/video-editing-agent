# R0.7B Reference Style Evidence Scope

Status: **ENGINEERING BATCH IN VALIDATION**

## Purpose

R0.7B reference analysis is deliberately narrower than later media-evidence phases. It derives only
what current exact `Shot` and `ShotAnalysis` revisions can support, then stores the abstraction as a
content-addressed JSON artifact.

The active chain is:

```text
reference Asset (reference_analysis_only)
→ exact Shot revisions
→ exact ShotAnalysis revisions
→ deterministic structural/style aggregation
→ content-addressed ReferenceStyleEvidence artifact
→ abstract planning guidance
```

## Supported evidence in this batch

- shot count;
- exact rational total/minimum/median/maximum shot duration;
- opening framing and camera-motion observation;
- framing sequence and frequency;
- camera-motion sequence and frequency;
- recurring action, subject and environment observations.

These are abstract technique/structure observations. They are not permission to copy wording,
distinctive visual expression or protected creative expression from a reference.

## Explicitly unavailable in R0.7B evidence

The service records these dimensions as unavailable rather than inventing them:

- caption density;
- music/cut relationship;
- speech structure;
- transition effects.

Those require evidence introduced by later speech/temporal/audio capabilities. R0.7B must not
silently implement R0.8 or R0.10 under a pre-production label.

## Source-eligibility invariant

The analyzer accepts only video Assets whose usage role is exactly:

```text
reference_analysis_only
```

The same Asset remains ineligible for visual Resolver use. Reference analysis never reclassifies the
Asset and never creates editable source authority.

## Persistence class

`ReferenceStyleEvidence` is a Derived Artifact / Value Object, not a tenth top-level Domain Entity.
The JSON payload is stored behind the existing content-addressed `ArtifactStore`; exact Asset, Shot
and ShotAnalysis revisions are preserved in the payload for provenance and cacheability.
