## Authority/persistence evidence

The live provider emitted real timed segments and words.

Repository tests verify:

- provider timestamps become Shot-relative proposals;
- owner validation maps them onto original Asset rational time;
- words/segments cannot escape the exact Shot;
- invalid/out-of-order provider proposals commit nothing;
- transcript revisions persist/reload via SQLite;
- `vad_filter=False` remains enforced.

The live provider and deterministic owner/persistence surfaces were validated separately rather than through one monolithic live SQLite harness.
