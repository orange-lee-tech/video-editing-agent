## Technical Product Probe

The hardened real-pipeline Product Probe passed all ten named gates. It did not preselect winning ShotCandidate identities, CandidateWindows or answer source ranges.

Observed pipeline:

`managed manifest → lexical index → E5 dense index → RRF → OpenCV motion → event reducer → canonical CandidateWindow generator → Resolver/optimizer → FFmpeg diagnostic previews`

The probe generated 15 CandidateWindows. Example accepted selections remained exact generated source windows and unsupported intent remained explicitly unresolved. R0.9A/R0.9B regressions and the full repository Quality Gate were green.

## Human Gate

The user reviewed the local diagnostic previews on 2026-08-13.

Human findings:

- visual selections: acceptable; no material visual-selection defect reported;
- trim/cut points: acceptable;
- sequence preference / Resolver superiority: inconclusive because the small comparison did not provide a sufficiently clear human evaluation scale; no negative sequence finding was reported;
- audible speech/audio: not heard in the previews and not accepted as an R0.9 capability.

The Human Gate therefore accepts R0.9 for its actual Exit Gate: creation of a grounded exact source-selection plan from real local footage without LLM timestamp invention. It does **not** claim that the Resolver has proven broad human-preference superiority.

## Limitations carried forward

- The current corpus is small and product-oriented; it is not a broad style/diversity benchmark.
- Semantic retrieval in this closure uses human-confirmed managed-corpus coverage text as ShotAnalysis input; broader automatic visual-semantic quality remains outside this closure claim.
- Sequence preference superiority is not established by this Human Gate.
- Audio audibility, music selection, BeatMap quality, ducking, fades and mix quality are explicitly outside R0.9 and move to R0.10.

## Exit decision

R0.9 is CLOSED.

The project may proceed to R0.10 — Music Selection + BeatMap + Audio Editorial.
